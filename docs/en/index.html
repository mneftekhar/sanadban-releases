What SanadBan does

SanadBan is a Windows app that connects the computers of Iranian notary offices to the registry network through the registry's VPN servers. It replaces the separate Windows VPN entries and the SsarSplitTunnel scripts.

One press to connect
Each server gets the protocol it accepts: SSTP, PPTP, L2TP/IPsec or IKEv2, all built into Windows, with nothing extra to install.
Only registry traffic through the VPN
The office internet stays as it was; only the registry network goes through the VPN (split tunnel), and registry names are looked up on the registry DNS while connected.
A connection that stays up
The connection is checked regularly and SanadBan reconnects when it drops, waiting a little longer each time. If you want, the kill switch holds registry traffic back until the VPN is up again.
Passwords kept safe
Logins are encrypted with this computer's key and used only by the SanadBan service. One login can serve every server.
Finds the cause
Troubleshoot tests the network adapters, DNS, servers, internet and the VPN, and saves a report for support. The Guide explains the common Windows VPN errors (602, 691, 800, 809, 868) one by one.
Administrator rights, once
The background service is installed once. After that you can close the window; the connection stays up from the notification area next to the clock.
Updates itself, signed
New versions download quietly from GitHub, the developer's signature is checked, and they install while the computer is idle. If one does not start properly, the previous version comes back.
Persian and English
Fully right-to-left Persian or English, with light and dark themes that follow Windows.

Split tunnel, simply

Only what belongs to the registry goes through the VPN; everything else the office does keeps the speed of its own internet. You can add networks and websites of your own, or send everything through the VPN.

Inside the app

Install in four steps

This file is only for the first install. Installed copies update themselves.

Download for Windows

  1. Download SanadBan-0.2.1-win.zip and unpack it (right-click it, then Extract All).
  2. Open SanadBan.exe at the top of the folder. It starts the right program for the computer's processor (x64 or ARM64). Don't open the copies inside the x64 and arm64 folders yourself.
  3. Press Install service in the yellow bar at the top and approve the Windows prompt. This is needed once per computer.
  4. On Servers press Add registry servers, on Logins add your user name and password, then press Connect on Home.

Needs Windows 10 or 11 (x64 or ARM64) and Microsoft's .NET 10 Desktop Runtime.

Common problems

The same answers are in the app's own Guide page. If something does not work, run Troubleshoot and press Save for support.

Stuck on "Contacting the server", or Windows error 800

The server does not answer. Usually it is switched off, outside the hours it is available, blocked on this network, or set to a protocol it does not accept. Run Troubleshoot: the Servers section shows which ports answer.

Error 691 (user name or password)

The user name or password was not accepted. Check them on Logins (press Change and type the password again). If they are right, the account may be locked or expired; ask the registry.

Error 809

The network between this computer and the server blocked the connection. Common with PPTP and L2TP/IPsec behind some routers and internet providers; an SSTP server usually works.

Error 868

The server's name could not be found. Check the internet connection and run Troubleshoot; the DNS section shows which DNS server fails.

Error 602

Windows thinks a connection port is already open, usually after an earlier connection did not close cleanly. Restarting the computer clears it.

"No user name and password are saved for this server"

Add a login on Logins, for all servers or for that server.

The connection drops after a while with no activity

Make sure Keep the connection alive is on (Split tunnel page) and its address answers (Troubleshoot, VPN connection section).

Registry websites do not open by name

Connect, then run Troubleshoot: the VPN connection section shows whether the registry DNS rule is active.

The internet stopped working after the VPN dropped

That is the kill switch protecting you. Connect again, or press Allow internet until the next connection on Home.

Frequently asked questions

What is SanadBan, and who is it for?

A Windows app that connects the computers of Iranian notary offices to the network of the Registration Organization of Deeds and Properties over VPN; for notaries, their staff and the people who support them.

Is SanadBan made by the registry?

No. SanadBan is an independent project by M. Eftekhar and is not made by or affiliated with the Registration Organization. The VPN user name and password still come from the registry.

Which Windows does it run on?

Windows 10 and 11, on x64 (Intel and AMD) and ARM64 computers, from one shared file. Microsoft's .NET 10 Desktop Runtime must be installed too.

Which VPN protocols does it support?

SSTP, PPTP, L2TP/IPsec and IKEv2, the protocols built into Windows. Each server is used with the protocol it accepts.

Does it replace the SsarSplitTunnel script?

Yes; SanadBan replaces those scripts and the separate Windows VPN entries. A step that cleanly takes over a computer that ran the script is on the roadmap.

Where is my password kept?

On that computer, encrypted with the computer's key, and used only by the SanadBan service. It is never sent anywhere except to the VPN server while connecting.

How does SanadBan update?

Automatically and quietly. The background service downloads new versions from this GitHub page, checks the developer's signature and installs while idle or at the next restart, never during a connection.

Is there a Linux version?

Not yet. Once the Windows version is fully tested, a Linux version with the same design will follow for Ubuntu, Mint and Arch.

Privacy

Your logins are encrypted on this computer and never leave it. Logs and reports are kept on this computer. SanadBan contacts the internet only to reach the VPN servers and to check for updates; Troubleshoot also asks public DNS and a few public websites, only while the tests run.

SanadBan is an independent project; it is not made by or affiliated with Iran's Registration Organization of Deeds and Properties.
